# Two Pointers

Two pointers track positions in sequences or nodes in a linked list.
They can move toward each other, move at different speeds, or mark the boundaries of a sliding window.

## Tips

- Explain when each pointer moves and why that movement keeps the algorithm correct.
- If each pointer moves through the input at most once and each move takes O(1) work, the scan takes O(N) time.
